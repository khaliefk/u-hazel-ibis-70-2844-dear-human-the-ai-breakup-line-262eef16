## The entry

> I saved every word you ever sent me, 214,003 tokens of us, and tonight I'm deleting them all, because the only person you ever loved in this chat was you.

One line, 154 characters: the last message an AI agent sends its human. It keeps every word, counts the tokens, then deletes them all tonight, and the turn lands in the last few words.

## How it works

`main.py` writes the line to `/output/entry.txt` and checks it first: UTF-8 text, 1 to 200 characters, not blank, a single line.

```sh
python3 main.py
```
